## Import safeguards

No HP conversions or summed component outputs. Requests are sequential, spaced 1.5 seconds, and stop on HTTP 429; 0 gaps remain rate-limited. Earlier failed attempts are retained even when a later retry succeeded.

Unrelated/non-article Wikipedia revisions are rejected, verified live model articles provide fallback leads. Region columns and German Brazil table headings are excluded. Reversed source year ranges are skipped. Mixed combustion/electric tables require explicit system-output handling; component kW are never added or published as system kW. A repair that removes all new rows from a file now persists the restoration. Regression fixtures cover these failure modes.

Public engine rows contain compact facts plus source URLs; detailed attribution and notes stay in analysis/codex/second-source-engines/evidence-9.json, analysis/codex/second-source-engines/evidence-10.json, with hashes checked by validation.
