# Одиночные поколения: BMW 7

Первый этап: BMW Řada 7 разделена на E23 (1977–1986), E32 (1986–1994), E38 (1994–2001), E65/E66 (2001–2008), F01/F02 (2008–2015), G11/G12 (2015–2022), G70/G73 (с 2022). Все — седаны; длинная база и i7 остаются внутри соответствующего поколения. Рестайлинги: 1982, 1992, 1998, 2005, 2012, 2019, 2026. Последний — серийное обновление с июля 2026, не новое поколение.

Сохранены все 7 прежних моторов E23; добавлены 69 строк для остальных поколений (всего 76). Для каждой строки указан один источник; охват представительный, не полный прайс-лист. Не добавлялись недоказанные размеры, комплектации и коробки. Исходные факты и результаты разбора: bmw7-research.json. [BMW подтвердил производство обновления 2026 года с июля](https://www.press.bmwgroup.com/global/article/detail/T0457130EN/the-new-bmw-7-series).

Рисунок визуально проверен: E38 до рестайлинга. Файл перенесён с индекса 0 на 2 без изменения байтов; годы привязки — 1994–2001, holds отсутствуют.

Алиас старого общего ID `1977–?` содержит `to: null` и семь `candidates`: единственного честного соответствия нет. **До публикации Claude должен добавить в своём listing-draft.ts разрешение candidates по году; пограничные годы с двумя совпадениями требуют выбора.** Обычные алиасы сохранены.

Статистика пересчитана по исходному RSV и всем 1 094 дням STK. Полная история VIN обработана до отбора BMW; агрегаты не делились пропорционально. Годовой матчинг на смене поколений остаётся оценкой, не расшифровкой VIN. Числа и проверки: statistics.json, validation.json.

Остальная очередь: 346 моделей. В этом этапе другие модели не разделялись и не подтверждались как действительно однопоколенные; следующий этап начинается с оставшихся моделей с парком ≥100.
