## Matcher correction and raw rebuild

A single candidate no longer bypasses dates. Dated generation intervals take precedence over stale model-line bounds (regressions cover Gladiator SJ, modern Commander, Cerato and Baleno). If all generations are dated and none contains the year, the record stays in make totals and is not assigned to that line. Undated families remain a fallback, not an assertion that every year belongs to a generation. Existing multi-candidate deterministic ordering remains unchanged.

Prewar Mercedes 300/350: previously 1328 fleet records; now no publishable line group. Later badge records are no longer counted as prewar cars. All recomputed make totals remain unchanged. Per-line count changes and disappearances are recorded in statistics-rebuild.json.

The stricter matcher changes 79 line-level fleet/STK metrics, not only Mercedes. These are date-based exclusions, not reassignment to another model. Catalogue omissions or first-registration year proxies can also put a real vehicle outside recorded production bounds; individual exclusions have not been manually reviewed. Make totals include those records.

Complete rebuild requested 28 makes; 17 have publishable aggregates. IS TP: all 1,094 days, 2023-10-12–2026-10-11. RSV: vypisvozidel.csv snapshot built 2026-10-31. Every staged statistics key was checked against current generations before publication. Across recomputed makes, 135 fleet lines were checked, 120 have generation aggregates; all 15 empty cases are audited against raw years/sample counts. No eligible raw group of 30+ was dropped. listing-stats.json regenerated. Matcher inputs fingerprinted.

The first raw run was interrupted after a regression check found stale line-level bounds; only the complete rerun using the corrected generation-first matcher was finalized. Ignored staged/ artifacts are local rebuild output, not files to commit.
