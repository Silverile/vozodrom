# Reference selection gate

Image generation may start only after the reference passes every check below.

1. Confirm the exact manufacturer, model line and catalogue generation from at
   least two independent sources. A search-result caption alone is not evidence.
2. The photograph must show the complete front of the car. A head-on view is
   preferred; a front three-quarter view is acceptable when the grille, both
   headlights, both bumper corners and the bonnet shape are visible.
3. Side, rear, rear-three-quarter, cropped-detail and heavily obstructed views
   are rejected. They must never be used to invent an unseen front elevation.
4. Separate factory equipment from accessories. Bull bars, auxiliary lamps,
   cargo canopies and other add-ons must not determine the generated front.
5. Save the source page, direct image URL, author/licence when available, exact
   variant, view assessment and two-source identity evidence before ImageGen.
6. A second reviewer must compare the saved reference with the drawing. If the
   reference itself fails this gate, the result is rejected regardless of how
   plausible the drawing looks.

The batch reference audit is a required input to final validation. `reject`
means that the reference must be replaced and the drawing regenerated.
