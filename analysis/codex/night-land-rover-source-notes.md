## Offline rebuild

The exact eight-command sequence is retained as `rebuildOrder` in both make reports. It runs both builders, the Land Rover historic refinement, Lexus current-version and final refinement scripts, the shared photo finalizer, then both strict validators. Retained photo batches001–004 need no downloads or further selection. The finalizer expects freshly built null photo fields and must not be rerun directly against finished cards. This complete sequence was not rerun as one operation after finalization; its individual stages and the final validators were run during creation. Later parent integration edits are outside these worker builders.
