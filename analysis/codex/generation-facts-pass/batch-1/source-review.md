# Проверка источников кузовов

Положительные факты записаны в `body-facts.json`: один URL на каждый тип кузова, точное поколение/раздел в `anchor`, способ проверки и пояснение. В исходных карточках это `bodyTypeEvidence`; публичный индекс сохраняет общие ссылки поколения. Индивидуальный тип кузова не доказывает полноту списка кузовов всей семьи.

- Continental, собственный каталог 2025: PDF загружен и извлечён в UTF-8; проверены названия применений с кодами поколений. `catalogue-headings.json` сохраняет заголовки для воспроизводимости. Диапазоны применяемости деталей не перенесены в годы производства. Числа размеров аккумуляторов не использованы.
- Dolz, собственный каталог: PDF загружен и извлечён; найдено отдельное применение `LANCER IV Stufenheck (C6_A)`, 1990–1992. Оно дополняет заводское подтверждение хэтчбека Lancer 1988.
- Sidem, собственный каталог BEV 2025: PDF загружен и извлечён; проверены отдельные применения E-Doblò MPV и Box Body/MPV с кодами 510/511, началом 2022. Не выводим пассажирский MPV из одного слова MPV в смешанном заголовке фургона.
- Mazda, Audi, Fiat/Stellantis, Škoda и Mercedes-Benz: проверены соответствующие заводские публикации, руководства или индексируемые тексты оригинальных документов. Предшественники, концепты и похожие названия не подтверждают кузов нужного поколения автоматически.
- Mitsubishi: общий заводской исторический справочник проверен по отдельным секциям Lancer 1973, EX 1979, Fiore 1982/1983, Lancer 1988/1991/1995. Код кузова универсала дополнительно проверен в собственном каталоге Continental или Millard. Групповое название раздела `Sedan, Hardtop type / Hatchback type` само по себе не принято за доказательство всех этих кузовов.
- Технические версии: заимствован только кузов конкретной уже проверенной версии того же поколения. Сохранены имя, URL и SHA-256 полного исходного объекта; размеры и прочие цифры версии не скопированы на поколение.

Ограничения доступа: оригинальный пресс-лист Audi of America MY2010 на Audiworld и каталог Haynes July–December 1997 проверены по индексированным выдержкам оригинальных документов. Прямая загрузка первого возвращала 403, второго — timeout. Для Haynes выдержка явно связывает Fiat 126 Saloon с воздушным охлаждением 594/652 см³, 1973–1987; не с BIS. Наличие полных документов по этим адресам сейчас не подтверждено. Страницы старого Stellantis Heritage перенаправляются на Heritage Hub Italy; проверено содержимое статьи после перенаправления.

Исходные полные сторонние PDF и их текстовые копии служили временными файлами исследования и удалены перед передачей; в репозитории остаются ссылки, короткие указатели и проверенные факты.
