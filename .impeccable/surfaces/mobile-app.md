# Mobile app (Expo) — surface brief

Scope: the native Vozodrom app in mobile/ (iOS + Android), mode Operate. Audience: Czech used-car buyers, owners writing logbooks, sellers, moderators and admins. Every web feature including admin and catalogue edits lives in the app. Approved board: design/mobile/jasne/index.html.

## Direction contract

THESIS: A first-time user knows where everything is without learning anything: photo-first listings and posts, every figure labelled, five labelled tabs with a central "+". Refuses metaphors (passport, rally, brochure), which the user rejected as confusing.
OWN-WORLD: Site Asfalt tokens (dark #0d0f12 / light #f4f6f8, teal brand #2fd0a0 / #0b8466, orange action #ff6a2a / #b83f08); Barlow; 14–16 px cards, labelled stat grids, pill chips; orange only for the primary action.
STORY: Search or browse, judge a car by labelled facts and owners' experience of its generation, message the seller; owners add logbook entries via "+".
FIRST VIEWPORT: Domů: title, big search field, Auta/Stroje/Díly tiles, horizontal new-listing cards, owner stories; tab bar Domů · Hledat · + · Zprávy · Profil; staff reach Správa from Profil.
FORM: Category standard (canon) chosen after four rolls; seed: seed:bb2959601932fd2e
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
